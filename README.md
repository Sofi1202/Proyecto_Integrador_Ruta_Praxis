# 📌 Descripción general

Ruta Praxis es una aplicación desarrollada en Java orientada a la gestión integral, seguimiento y evaluación de las prácticas académicas realizadas por estudiantes del programa de Licenciatura en Educación Infantil.

El software fue diseñada para centralizar y optimizar el proceso de práctica pedagógica, permitiendo el registro organizado de actividades, bitácoras y evidencias, así como el acompañamiento permanente por parte de tutores académicos y asesores pedagógicos. De esta manera, se fortalece la trazabilidad del proceso formativo, se mejora el control académico y se facilita la evaluación del desempeño estudiantil.

El sistema integra en un único entorno:

- ✔ Gestión y seguimiento de prácticas académicas
- ✔ Registro de actividades y bitácoras pedagógicas
- ✔ Carga y administración de evidencias digitales
- ✔ Seguimiento y acompañamiento por tutores académicos
- ✔ Supervisión y observaciones por asesores pedagógicos
- ✔ Evaluación y retroalimentación del desempeño estudiantil
- ✔ Consulta del historial completo de prácticas
- ✔ Control y validación del cumplimiento de horas de práctica
- ✔ Gestión centralizada de la información académica
- ✔ Interfaz gráfica desarrollada en Java Swing con enfoque en usabilidad y accesibilidad
